# Notes

Notes for this repo, written mostly in question-and-answer form.

## Format

Notes are grouped by git branch. Each branch gets a section heading with the branch name and a one-line summary of what the branch does:

```
## <branch-name>: <one-line summary of what the branch does>

### Q: <question>
A: <short answer>
```

## Files

- `qa-log.md`: running Q&A log, newest branch and newest entries at the top.
